🔑 Pasar llaves

Conecta Hugging Face a tu nube copiando todo de una sola vez (o con una captura). Sin brincar entre apps.

🔒 Código de acceso

🛡️ La captura se lee aquí dentro de tu celular; no se sube a ningún lado. Solo las 2 llaves viajan cifradas a tu propia nube.

1En Hugging Face

En tu token nube-jairo toca ⋮ → Generate S3 credentials. Cuando salgan las 2 llaves:
  1. Mantén presionada la palabra "Access" (o cualquier texto de esa ventanita).
  2. En el menú que sale toca Seleccionar todo.
  3. Toca Copiar. Así se copian las 2 llaves juntas, de una sola vez.
  4. Por si acaso, toma también captura de pantalla.

2Pega lo que copiaste (lo más exacto)

2b¿No se pudo copiar? Usa la captura

📷 Toca para elegir la captura

3Revisa las llaves

Compáralas con la captura de arriba (puedes deslizarla). Si alguna letra salió mal, corrígela aquí mismo. Ojo con 0/O, 1/l/I y 5/S.
